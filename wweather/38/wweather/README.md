# WWeather (허리 날씨 앱) - 정리본

기압(방재기상관측, AWS), 강수(오늘 비 옴/안옴), 현재 온도, 풍향/풍속/습도, 현천(WW1) 정보를 보여주는 Android 앱입니다.  
기상청 APIHub(typ01) `nph-aws2_min`, `nph-aws2_min_ww1` 데이터를 사용합니다.

기본 동작은 **사용자 위치 기반 관측소 선택**이며, 이번 수정으로 **수동 지역 선택 기능**이 추가되어 원하는 지역으로 바로 조회할 수 있습니다.

---

## 현재 주요 기능

### 1) 기본 위치 기반 조회
- 앱 시작 시 기본값은 **사용자 현재 위치 기준**입니다.
- 가장 가까운 관측소(stn)를 선택해 날씨를 조회합니다.

### 2) 수동 지역 선택 조회 (신규 반영)
- 기존 **[설정 열기]** 버튼은 제거되었습니다.
- 같은 위치의 버튼은 **[지역 열기]** 로 텍스트만 변경되었습니다.
- 버튼의 UI 디자인은 유지하고, 기능만 지역 선택용으로 변경했습니다.
- **[지역 열기]** 클릭 시 지역 선택 다이얼로그가 열립니다.
- 다이얼로그에서 지역을 선택한 뒤 **[확인]** 을 누르면 해당 지역의 날씨 정보로 즉시 전환됩니다.
  - 예: 독도 → 서울, 제주도 등으로 변경 가능

### 3) 지역 검색 기능 (신규 반영)
- 다이얼로그 안에 검색 기능이 추가되었습니다.
- 초성 검색은 아니지만, **부분 문자열 검색** 방식으로 동작합니다.
  - `제주도`는 `제주`, `제` 입력으로 검색 가능
  - `서울`은 `서` 입력 시 `서`가 포함된 지역 목록이 표시됨
- 선택 다이얼 옆에 검색 관련 버튼과 제어 버튼을 함께 배치했습니다.

### 4) 지역 선택 다이얼로그 내 버튼 구성 (신규 반영)
다이얼로그에는 아래 버튼이 배치됩니다.
- **검색**
- **나가기**
- **초기화**
- **고정**
- **확인**

각 기능은 다음과 같습니다.
- **검색**: 입력한 단어로 지역 목록을 필터링
- **나가기**: 다이얼로그 닫기
- **초기화**: 수동 선택 / 고정 상태를 해제하고 기본값(사용자 위치 기준)으로 복귀
- **고정**: 현재 선택한 지역을 앱 시작 시 자동 표시되도록 저장
- **확인**: 현재 선택한 지역으로 즉시 조회 적용

### 5) 고정 기능 (신규 반영)
- 특정 지역을 **고정**하면 앱을 다시 켤 때마다 그 지역이 자동으로 선택됩니다.
- 예: 서울을 고정하면 다음 실행부터 서울 기준으로 조회

### 6) 재접속 동작 개선 (오늘 추가 수정)
- 이전에는 지역을 변경해도 **[재접속]** 시 사용자 현재 위치 기준으로 다시 접속되는 문제가 있었습니다.
- 현재는 아래처럼 동작합니다.
  - 지역 선택 후 **[확인]** → 그 지역이 현재 접속지가 됨
  - 이후 **[재접속]** → 현재 선택된 지역으로 다시 조회
  - **고정 지역**이 있으면 고정 지역 기준 재접속
  - **초기화** 후 재접속하면 다시 사용자 위치 기준으로 동작

## 유지되는 기존 기능

### 기압 표시 및 상태 표시
- 설정한 기압 범위(최소/최대) 기준으로 상태를 판단합니다.

### 오늘 강수(비 옴/안옴) 판단
- `RE > 0` 또는 `RN-15m / RN-60m / RN-12H / RN-DAY` 중 하나라도 `> 0`이면 비가 오는 것으로 판단합니다.

### 현천(WW1) 코드 표시
- `nph-aws2_min_ww1` 데이터를 조회해 현천코드를 표시합니다.
- 하단 범례는 가로 스크롤로 확인할 수 있습니다.

### 현재 온도 표시
- `TA` 값을 읽어 표시합니다.
- 표기 형식은 정수 + `º` 입니다.

### 풍향 UI
- **[풍향 UI]** 버튼을 누르면 풍향계/나침판 팝업이 열립니다.
- 풍향과 방위를 함께 확인할 수 있습니다.

### 이미지 저장 / 공유
- 현재 메인 화면을 PNG로 저장할 수 있습니다.
- 저장한 이미지를 공유할 수 있습니다.

### 로그 보기
- 앱 내부 진단 로그를 확인, 복사, 공유할 수 있습니다.
- **[재접속]** 시 로그는 자동 초기화됩니다.

## 오늘 변경 사항 정리

### 추가된 내용
- **[지역 열기]** 기능 추가
- 지역 선택 다이얼로그 추가
- 지역 검색 기능 추가
- **검색 / 나가기 / 초기화 / 고정 / 확인** 버튼 추가
- 고정 지역 저장 기능 추가
- 선택 지역 기준 재접속 기능 추가

### 변경된 내용
- **[설정 열기]** → **[지역 열기]**
- 버튼 UI는 그대로 유지, 텍스트와 기능만 변경
- 재접속 기준이 기본 위치 우선에서 **현재 선택 지역 우선**으로 개선됨

### 제거된 내용
- 기존 **설정 열기 메뉴 기능** 제거
- 설정 화면으로 진입하던 역할 제거

## 현재 동작 기준 요약

1. 앱 최초 실행
- 기본값은 사용자 위치 기준 조회

2. 지역 열기 → 서울 선택 → 확인
- 현재 접속지가 서울로 변경됨

3. 재접속
- 서울 기준으로 다시 조회됨

4. 고정
- 서울을 고정하면 앱 재실행 시에도 서울로 자동 조회

5. 초기화
- 고정/수동 선택 해제
- 다시 사용자 위치 기준 조회로 복귀
