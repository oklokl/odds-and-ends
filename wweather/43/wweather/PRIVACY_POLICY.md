## 1. 처리하는 정보 항목 및 수집 방법

앱은 회원가입, 로그인, 광고, 마케팅, 행태분석(Analytics) 기능을 제공하지 않으며, 서비스 제공에 필요한 최소한의 정보만 이용자의 명시적 동작과 동의를 거쳐 처리합니다.

### 가. 전경(앱 사용 중) 1회성 대략적 위치정보 (`ACCESS_COARSE_LOCATION`)
- **수집 시점**: 앱 시작 시 자동으로 위치를 조회하지 않으며, 이용자가 **[재접속]** 버튼을 눌러 위치 확인 안내에 동의한 경우에만 1회 조회합니다.
- **수집 범위**: 정밀 위치(`ACCESS_FINE_LOCATION`) 및 백그라운드 위치(`ACCESS_BACKGROUND_LOCATION`)는 요청·수집하지 않으며, Android OS가 제공하는 **대략적 위치(약 2~3km 오차 범위)**만 사용합니다.
- **이용 목적**: 가장 가까운 기상청 관측소 매칭, 현재 행정구역(시/군/구) 표시, 기상청 또는 Open-Meteo 날씨 조회.
- **선택권**: 위치 권한을 거부하더라도 **[지역 열기]** 메뉴에서 지역을 직접 선택·고정해 모든 기능을 이용할 수 있습니다.

### 나. 기기 내부에만 저장되는 앱 설정 및 캐시 정보
개발자 서버로 전송하지 않고 기기 내부 저장소(`SharedPreferences`, 앱 전용 파일 영역)에만 저장합니다.
- 마지막으로 확인·선택한 기상청 관측소 번호, 마지막 대략적 위도·경도, 마지막 행정구역명
- **[지역 열기]**에서 선택한 지역명, 좌표, 고정 여부
- 날씨 제공처 설정(`기상청` / `오픈메타`)
- 기상청 최근 관측 데이터 캐시(`nph-aws2_min.cache`, `nph-aws2_min_ww1.cache`) 및 캐시 메타데이터(관측소 번호, 저장 시각)
- 과거 버전의 백그라운드 알람·알림 플래그(`alert`, `condition`)는 현재 버전에서 자동 해제됩니다.

### 다. 진단 로그 (기기 메모리 임시 저장)
- 위치 조회 방식 및 정확도(m), 매칭된 관측소 번호, 행정구역명 판별 결과, API 요청·오류 상태를 기기 메모리(최대 120KB)에 임시 기록합니다.
- 정확한 위·경도 좌표는 로그에 직접 기록하지 않으며, 앱 재실행 또는 **[재접속]** 시 초기화됩니다.
- 이용자가 직접 **[로그] → [복사/공유]**를 실행한 경우에만 외부로 공유됩니다.

### 라. 화면 이미지 저장 및 공유
- 이용자가 **[이미지 저장]**을 누른 경우에만 현재 화면 PNG 이미지를 기기의 `Downloads` 폴더에 저장합니다(Android 9 이하에서는 `WRITE_EXTERNAL_STORAGE` 사용).
- **[공유]** 버튼을 눌러 다른 앱을 선택하기 전까지 외부로 전송되지 않습니다.

### 마. Google Play Age Signals (연령 신호)
- 법규·정책 준수를 위해 Google Play Age Signals API로 연령 범주(`ADULT` / `MINOR` / `UNKNOWN`)를 확인합니다.
- 원본 연령대는 기기 저장소·DB·파일에 영구 저장하지 않고 **프로세스 메모리 내에서만 일시 분류**하며, 광고·마케팅·프로파일링에는 사용하지 않습니다.

## 2. 백그라운드 실행 및 위치 추적 미사용
- 백그라운드 위치 권한, `Service`, `WorkManager`, 예약 알람 리시버를 사용하지 않습니다.
- 조회 중 앱이 백그라운드로 이동(`onStop`)하면 진행 중인 위치·지오코딩·네트워크 요청을 즉시 중단합니다.

## 3. 제3자 제공 및 외부 서비스 연동

개발자는 자체 서버를 운영하지 않으며 개인정보를 판매하거나 광고·마케팅 목적으로 제3자에게 제공하지 않습니다. 이용자가 조회를 요청한 시점에 한해 아래 서비스와 통신합니다.

| 연동 대상 | 사용 시점 | 전송/처리 정보 | 비고 |
| :--- | :--- | :--- | :--- |
| **기상청 APIHub** (`apihub.kma.go.kr`) | 기상청 모드 조회 시 | 관측소 번호(`stn`), 조회 기준 시각(`tm2`) | 위·경도 미전송 (일반 HTTPS 통신 IP 포함 가능) |
| **Open-Meteo** (`api.open-meteo.com`) | 오픈메타 모드 조회 시 | 대략적 위·경도(또는 수동 선택 좌표), 조회 파라미터 | HTTPS 암호화 전송 |
| **Android / Google Play 서비스** | 위치·행정구역·연령 확인 시 | 대략적 위치, 좌표→행정구역(`Geocoder`), Age Signals | 각 플랫폼 제공자 정책 적용 |

- **파기**: 개발자 서버 보관 데이터가 없으며, **[지역 열기] → [초기화]**, Android 설정의 **앱 데이터 삭제**, 또는 **앱 삭제** 시 기기 내 모든 데이터가 즉시 삭제됩니다.
- **권리 행사**: Android 설정 → 앱 → 허리 날씨 → 권한 → 위치에서 권한을 거부·철회할 수 있으며, 수동 지역 선택으로 계속 이용할 수 있습니다.
